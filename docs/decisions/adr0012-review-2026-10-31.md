# ADR-0012 Technical Review (independent, 2026-10-31)

**Reviewer scope:** ADR-0012 PROPOSED text vs actual PI-1, PI-3, PI-5, PI-4
implementations on `main` (`f169064` + drift-detector commit). This review
does NOT change the ADR's status. Acceptance is the operator's decision.

## 1. Substantive technical issues

**None blocking.** Three minor observations, none requiring amendment
before acceptance:

1. **Gate-mirroring duplication risk (accepted trade-off).** PI-1 and PI-3
   each hardcode the documented thresholds (50 GiB, 1.5 GiB). The ADR says
   "reuses — never weakens"; implementation mirrors rather than imports
   (`bootstrap.sh` is a shell script; Python import isn't available). This
   duplication is guarded: the PI-3 test suite drift-guards the threshold
   constants (`TestThresholdContract`), so a silent change to either side
   fails tests. Acceptable; documented here so the reviewer sees it was
   considered.
2. **"llm_inference_required: 0" is a contract field, not an enforcement
   mechanism.** Every verdict path sets it to 0 and every test asserts it,
   but nothing structurally prevents a future author from adding an
   inference call. The ADR's Phase-11 boundary remains a convention
   enforced by tests + review. This is inherent to the repo's
   deterministic-first doctrine (same as existing gates).
3. **PI-4 drift-vs-runtime boundary is a documented judgment call.** The
   detector excludes restarts/status as RUNTIME_VARIATION (readiness is
   PI-3's domain). A restart *explosion* could be either. Current split is
   clean and matches the ADR's separation principle; revisiting requires
   evidence, which the snapshot window will provide.

## 2. Recommended amendments

## 3. Implications of accepting

- PI-1…PI-6 deterministic layer becomes the **sanctioned** architecture for
  platform intelligence; future observability proposals must justify
  deviation from it.
- Resident stacks (PI-7) remain RED behind the capacity gate + separate
  authorization — acceptance changes nothing operationally today.
- Scheduled PI-1 snapshots (still gated separately) become the sanctioned
  evidence source for PI-2/PI-6.
- The zero-inference verdict contract becomes binding policy for all future
  PI-* tooling.

## 4. Recommendation

**ACCEPT** — technically sound, consistent with existing gates and the
operating model, and the implementations (PI-1 17/17, PI-3 20/20, PI-5
16/16, PI-4 21/21) match the ADR's four decision points. The ADR remains
**PROPOSED** pending the operator's decision; no status change has been
made and none should be inferred from this review.
