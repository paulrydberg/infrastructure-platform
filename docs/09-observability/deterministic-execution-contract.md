# Deterministic-Only Execution Contract (Platform Intelligence)

**Status:** Binding contract, established 2026-10-31 with ADR-0012 acceptance.
**Scope:** every scheduled or recurring execution path in this repository
(currently `bootstrap/pi1-snapshot-cron.sh` → `platform_state_collector.py`).

## The contract

Scheduled/recurring PI execution MUST be:

1. **Deterministic local code** — Python stdlib + existing host read-only
   interfaces. Identical inputs and host state produce structurally identical
   outputs and verdicts (timestamps and naturally-varying host values excepted).
2. **Zero LLM inference** — no calls to OpenAI, Anthropic, Z.ai, DeepSeek, or
   any other inference provider, directly or transitively.
3. **No agent/gateway invocation** — must not invoke Hermes, another AI agent,
   an inference gateway, or an LLM-backed plugin.
4. **No network requests** for inference, interpretation, or evidence
   processing.
5. **No credential dependence** — must not require API keys, provider
   credentials, or paid services.
6. **No silent fallback** — a failed local operation is never replaced by an
   LLM or remote service; it is recorded.
7. **Explicit deterministic rules** — evidence and verdicts are generated by
   code-inspectable rules (`llm_inference_required: 0` asserted in output).
8. **Visible failure** — a required local operation failing produces a
   `.failed` marker + stderr capture + non-zero exit, never a
   false-successful snapshot.

## Audit baseline (2026-10-31, verified before cron activation)

- `pi1-snapshot-cron.sh`: shell built-ins + `python3` + `date`/`mktemp`/
  `mv`/`rm`/`find`. No `curl`/`wget`/`ssh`/`nc`/`osascript`/agent invocations.
- `platform_state_collector.py`: imports exactly
  `{json, re, subprocess, sys, time, pathlib}` (stdlib only). Subprocess
  allowlist: exactly `df -g /`, `sysctl vm.swapusage`, `docker system df`,
  `docker stats --no-stream` ×2, `docker exec k3s-server kubectl get pods -A`
  — all local, read-only host interfaces.
- Whole-file primitive scan (socket/urllib/requests/http/curl/wget/ssh/nc/
  provider names/API keys/Popen/os.system/eval/exec): **CLEAN** — the only
  "llm" hits are the `llm_inference_required: 0` contract field itself.
- Reproducibility: two consecutive collector runs hash identically modulo
  timestamp/duration fields.
- Failure path verified live: the 03:17:01Z scheduled run executed during a
  Docker daemon gap, recorded four `probe_errors`, produced nulls for the
  failed probes, and still logged `ok` with the errors visible — nulls are
  data; the snapshot is honest about partial collection (per ADR-0012),
  while a *structurally invalid* or *collector-crashed* run produces
  `.failed` and exit 1.

## Change control

Any future change that introduces an LLM/inference/network dependency into a
scheduled path violates this contract and requires: (a) explicit operator
authorization, (b) an architecture review recorded as an ADR amendment, and
(c) re-running the audit (import enumeration + subprocess allowlist +
primitive scan + reproducibility check) with results recorded in
ROADMAP-STATUS. The audit script pattern is reproducible from this document:
enumerate AST imports, assert subprocess first-args ⊆ allowlist, grep the
primitive set, double-run structural-hash comparison.
